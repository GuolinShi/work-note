## 模块间关系速览

```text
SMS 审单 → WMS 占用库存；SMS 发货 → WMS 销售出库；SMS 截单/取消 → WMS 释放
SMS RMA 退货 → WMS 退件单 → 质检入库
PMS 采购审核 → SRM；SRM 完工 → PMS 完工单；PMS 质检入库 → WMS 采购入库
PMS 应付策略 → FMS 应付单 → 付款申请 → 付款单
WMS 头程：物流计划批次 → 调拨计划 → 发货单 → 收货入库（批次在途核销）
```
