# 采购（PMS）

采购由 `xzy-pms` 服务承担：商品与供应商主数据、销售计划、备货计划、报价、采购订单、完工（提货）、质检、采购入库、采退、结算调整与应付生成，并与 SRM 供应商门户、WMS、FMS 协同。

> 本文档 2026-09-04 基于 `xzy-erp-public/xzy-pms` 源码重新梳理，替代旧版。

## 核心对象

| 对象 | 模型 | 职责 |
| --- | --- | --- |
| 商品 | Spu / Product(SKU) / ProductSpec / ProductBox / ProductCustoms | SPU-SKU 体系；SKU 含组合品标记、虚拟品类型（SkuTypeNameEnum）、包装单箱数、海关信息 |
| 品牌/类目 | Brand / Category / SpuCategory | 商品分类 |
| 供应商 | Supplier / SupplierBank / SupplierAccount / SupplierItem / SupplierItemPrice | 供应商、银行账户、供应商品与价格、评审（SupplierReview） |
| 销售计划 | SalesPlan / Item / Snapshot / Excuse | 月度销售预测；审核通过后写入执行表（Excuse） |
| 备货单 | Stockup / StockupItem / StockupTrace | 备货计划；审核后生成备货追踪并推送采购计划同步任务 |
| 报价 | Quotation / QuotationItem / QuotationGroup | 报价单与报价组（含基准币种） |
| 采购单 | Purchase / PurchaseItem / PurchaseQcExtension | 采购主单+明细+质检扩展（抽检/全检、返工数、检验阶段） |
| 采购变更单 | PurchaseChange / Item | 已审核采购单的数量/价格等变更（新建→待审核→完成/取消） |
| 完工单（提货单） | Pickup / PickupItem | 供应商完工上报；新建→已确认→部分完工→完成 |
| 质检单 | Quality / QualityItem / QualityRecord / QualityExceed / QualityFreeSpu / QualityReturn | 初检/复检；超期与免检管理；质检状态：未质检→已质检→部份入库→完全入库 |
| 采退单 | PurchaseReturn / Item | 新建→待审核→待出库→已出库/取消；出库调 WMS（采退出库 -1） |
| 供应商结算 | SupplierSettlement / Item | 结算条款（结算比例、付款期限、时间节点），应付计算的依据 |
| 结算调整 | PurchaseSettlementAdjust / Item | 草稿→待审核→已审核/已作废；审核通过生成红字应付 |
| 财务出入库凭证 | FmsInbound / FmsOutbound | 提货完工入库/质检入库 凭证（未申请付款→已申请付款）；不良品退件出库凭证 |
| 采购调整 | PurchaseAdjustData | 采购调整数据（对应 WMS 采购调整出入库类型 ±7） |

## 采购单状态机（PurchaseStatusEnum）

| code | 状态 | 说明 |
| --- | --- | --- |
| 0 | 草稿 | 新建/审核拒绝退回 |
| 5 | 审核中 | 提交后 |
| 10 | 已审核（待下单） | 审核通过，推送 SRM |
| 20 | 待完工 | 下单/订金流程后（明细状态同步） |
| 21 / 22 | 部分完工 / 全部完工 | 按完工数量聚合 |
| 25 / 26 | 部分可入库 / 全部可入库 | 质检完成产生可入库量 |
| 30 / 40 | 部分已入库 / 全部已入库 | 质检入库后聚合 |
| -2 / -1 | 已取消 / 作废 | 终态 |

明细状态与主单同码；主单状态由 `calculateAndUpdatePurchaseStatus` 按有效明细（排除作废/取消）聚合得出（详见 [[采购生命周期与状态机]]）。

## 系统边界

- **上游**：销售计划→备货→采购；报价组提供单价与基准币种。
- **SRM**：采购单审核通过推 SRM（ADD）；反审核推删除（DELETE）；完工/质检变更推更新（UPDATE）；SRM 完工填报经 `addPickupBySrm` 回写 PMS 生成完工单。
- **WMS**：质检入库（自营仓）走 WMS 采购入库（PURCHASE_INBOUND，+1）；采退走出库（-1）；采购调整走 ±7。
- **FMS**：订金/尾款/结算调整应付单由策略工厂生成（DepositNormal/DepositRed/FinalPayment/FinalPaymentRed）；FmsInbound 凭证是申请付款的数据源。
- **并发控制**：采购单级锁 `PMS_OPERATE_REDIS_KEY+单号`、提交锁 `purchase:submit+id`；全局操作锁 `PMS_OPERATE_REDIS_KEY`。

## 流程总览

```text
销售计划(审核) → 执行表 → 备货单(审核) → 备货追踪 + 采购计划同步
报价/报价组 → 采购单(草稿→审核中→已审核[推SRM]) → 订金应付(可选)
  → 完工单(供应商/SRM上报→确认) → 更新采购数量 → 质检(初检/复检/免检) → 可入库量
  → 质检入库(自营仓走WMS/非自营仓记FmsInbound凭证) → 采购单状态聚合至 部分/全部已入库
  → 尾款应付(按结算条款) → 结算调整(红字应付)
采购变更单：已审核采购单的数量/价格变更流程
采退单：新建→审核→出库(调WMS采退出库)
```
