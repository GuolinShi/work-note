# 采购生命周期与状态机

> 代码依据：`PurchaseServiceImpl`（submit/audit/unAudit/cancel/cancelAll/cancelItem/calculateAndUpdatePurchaseStatus）、`PurchaseChangeServiceImpl`、`PurchaseStatusEnum`。

## 一、主流程步骤

### 1. 新增/编辑（add/update）
- 采购单=草稿（0）；明细含采购数量、单价、币种、交货日期等；质检扩展（抽检/全检、抽检比例、要求质检数）随单创建；
- 选择报价组时做币种换算：基准币种汇率取 **采购日期上个月** 的汇率版本；找不到汇率报"找不到币种[x]的汇率"，汇率必须>0；
- 编辑/删除边界：仅草稿可编辑、删除（删除前校验下游是否已产生完工等数据）。

### 2. 提交（submit）
- 加提交锁（`purchase:submit+id`）；**仅草稿可提交**，否则报"非新建状态不允许提交"；
- 主单+明细状态→审核中（5）。

### 3. 审核（audit）
- 加单号级锁；**仅审核中可审核**；
- **通过** → 已审核/待下单（10）：
  - 写备货追踪（备货单来源的明细记录采购下单数量）；
  - **推送 SRM**（MessageOperatorType=ADD）；
- **拒绝** → 退回草稿（0）（2026-04-17 起拒绝不再作废）。

### 4. 反审核（unAudit）
- **仅已审核（待下单）可反审核**；
- **存在未作废的订金应付单 → 拒绝反审**（"存在未作废的订金应付单，无法反审！"）；
- 回草稿，清空订金申请标记（isApplyDeposit=N、订金状态=未申请）；
- **推送 SRM 删除**（DELETE）。

### 5. 下单后（待完工）
- 订金申请通过后 `callBackPurchaseDepositApplyStatus(V2)` 把主单+明细推进到 **待完工（20）**；
- 此后由完工/质检/入库驱动状态（见 [[完工与质检入库流程]]）。

## 二、状态聚合（calculateAndUpdatePurchaseStatus）

主单状态 = 有效明细（排除作废-1/已取消-2）状态的聚合：

1. 全部明细作废 → 主单作废；全部明细取消 → 主单取消；
2. 按优先级统计有效明细中各状态数量：
   - 有"全部已入库(40)"且覆盖全部有效明细 → 全部已入库；
   - 有部分 40 或任何 30 → 部分已入库；
   - 26 全覆盖 → 全部可入库；有 26 或 25 → 部分可入库；
   - 22 全覆盖 → 全部完工；有 22 或 21 → 部分完工；
   - 有 20 → 待完工；
3. 任何完工/质检/入库/取消动作后都会触发重算。

## 三、完结与取消（结单）

### 1. 完结（cancel，订单完结）
- 把所有可取消明细的取消数设为 **采购数-良品数**（剩余未合格部分视为取消）；
- `checkPickup` 校验完工单情况；
- 无剩余可取消明细 → 主单置 **全部已入库（40，完结语义）**。

### 2. 整单取消（cancelAll）/ 明细取消（cancelItem）——红字冲销
- 前置：存在未取消数量（采购数-完工数-已取消数>0），否则报"无未取消的采购项"；
- **结单校验（checkCancel）**：
  - 待返工数、已返工数必须为 0（"待返工数或已返工数大于0, 不允许结单!"）；
  - 完工数 ≤ 良品数（"已完工数大于良品数, 不允许结单!"）；
  - 不存在未确认的完工单（"当前存在未确认的完工单，暂不支持结单!"）；
- 执行 **红字订金策略（DEPOSIT_RED）**：生成红字应付冲销订金，并把明细置为取消。

## 四、采购变更单（PurchaseChange）

状态：0 新建 → 1 待审核 → 2 完成 / -1 取消。
- 仅 **已审核的采购单** 可发起变更；同一采购单存在未完成变更单时不允许再开新单（`isExistChangeOrder`）；
- 提交→待审核；审核通过→完成并回写采购单（数量/价格等），同时联动备货追踪与 SRM；拒绝/取消→作废。

## 五、边界汇总

| 动作 | 允许状态 | 额外约束 |
| --- | --- | --- |
| 编辑/删除 | 草稿 | 无下游数据 |
| 提交 | 草稿 | - |
| 审核 | 审核中 | 通过推 SRM |
| 反审核 | 已审核 | 无未作废订金应付单 |
| 完结 | 有可取消余量 | 完工校验 |
| 整单/明细取消 | 有未取消数量 | 无返工余量、完工≤良品、无未确认完工单；走红字冲销 |
| 变更 | 已审核 | 无在途变更单 |
