# 完工与质检入库流程

> 代码依据：`PickupServiceImpl`、`QualityServiceImpl`、`handler/srm/*`、`PurchaseQcExtensionServiceImpl`。

## 一、完工单（Pickup）

状态（PickupStatusEnum）：0 新建 → 5 已确认 → 10 部分完工 → 15 完成。

### 1. 创建
- **手动新增**：按采购单选明细录入本次完工数/返工数，校验同 [[采购数量与状态约束]]（完工数≤待完工数、返工数≤待返工数）；仓库默认采购单仓库，无则取供应商仓库；
- **导入**：批量导入完工（按采购单分组校验）；
- **SRM 完工填报**（`addPickupBySrm`）：
  - 入参校验（采购单号、明细非空）；采购单必须存在；
  - **防重**：同一采购单+完工单号（finishNo）不允许重复；
  - 直接生成 **已确认** 状态的完工单（跳过新建→确认），走与手动确认相同的后续处理。

### 2. 确认（confirm）
- **仅新建可确认**（"提货单已经非新建状态，不能再次确认"）；
- 状态→已确认，随后：
  1. 更新采购明细：完工数累计、明细状态重算（`calculateItemStatus`）、抽检/全检的待初检/待复检数计算；
  2. 写备货追踪（提货数量）；
  3. 免检明细自动加良品数并置质检完成（`handleExemptionPickup`）；
  4. **完工入库**（`addQualityInbound`）：
     - 调 WMS 入库，业务类型=**完工入库（QUALITY_INBOUND，+6）**；
     - 入库数量 = min(本次完工数, 良品缺口)，良品缺口 = 采购明细良品数 - 此前已完工数，缺口≤0 则不入库；
  5. 重算采购单主状态；
  6. 推送 SRM（采购单 UPDATE、完工单 ADD）。

### 3. 批量操作
- `batchAddQc`：按完工单批量生成质检单；`batchConfirm`：批量确认。

## 二、质检单（Quality）

质检状态（QualityStatusEnum）：0 未质检 → 5 已质检 → 10 部份入库 → 15 完全入库。
明细状态（QualityItemStatusEnum）：未开始 → 待完工 → 部分可质检/可质检 → （待返工）→ 部分质检完成/质检完成；检验阶段：初检/复检。

### 1. 生成
- 完工确认后可生成质检单（一完工单一质检单）；免检商品（QualityFreeSpu，按 SPU 维护、有状态有效期）不质检直接计良品。

### 2. 质检（addQc / update）
- 录入合格数（良品数）与不良品数；不良品可转返工（待返工数增加，触发复检）；
- 质检完成后：采购明细良品数/不良品数累计 → 产生 **可入库量**（采购明细状态进入 25/26）；
- 质检报告（文件）上传存档并同步 SRM。

### 3. 质检入库（inbound）
- 校验：明细非空、入库数非全 0、库存层级必填；
- **入库上限**：良品数+不良品数-已入库数，超出报"超过最大可入库数量"；
- 乐观锁更新入库数（失败报"SKU【x】入库失败"）；
- 状态联动：入库合计=良品合计→完全入库；入库合计<良品合计→部份入库；
- 入库成功后：
  1. **生成采购入库**（`addPurchaseInbound`）：调 WMS 入库，业务类型=**采购入库（PURCHASE_INBOUND，+1）**；
     - 批次价=采购明细未税单价；币种=采购单币种；
     - 追加校验：**已入库+当前入库 ≤ 已通过质检记录的数量**，否则报"已入库数量x+当前入库数量y 小于 已通过审核的质检数量z"；
  2. 更新采购明细入库数、采购单状态聚合（30/40）；
  3. **财务凭证**：入库仓为 **非自营仓** 时额外生成 FmsInbound（类型=质检入库，未申请付款）；自营仓不生成（WMS 库存账已落地）；
  4. 更新质检超期提醒（QualityExceed）；写备货追踪（入库数量）。

### 4. 质检超期与免检任务
- `QualityExceedHandleJob`：统计质检超期数据并提醒；
- `QualityFreeSpuStatusJob`：维护免检 SPU 状态有效期。

## 三、SRM 消息同步

- 采购单：审核通过（ADD）、反审核（DELETE）、完工/质检变化（UPDATE）；
- 完工单：确认/新增（ADD）；
- 质检单：质检完成（含报告下载地址）推送；
- 消息失败记错误类型（ErrorMsgTypeEnums）供告警。

## 四、边界汇总

| 环节 | 边界 |
| --- | --- |
| 完工确认 | 仅新建；数量不超待完工/待返工 |
| SRM 完工 | 单号防重；直接进已确认 |
| 免检 | 免检 SPU 完工即良品，不生成质检任务 |
| 完工入库 | 数量=良品缺口；业务类型=完工入库(+6) |
| 质检入库 | 上限=良品+不良-已入库；必须选库存层级；不超已通过的质检数量；业务类型=采购入库(+1) |
| 财务凭证 | 仅非自营仓生成 FmsInbound |
| 复检 | 返工触发复检阶段，复检合格后良品数才增加 |
