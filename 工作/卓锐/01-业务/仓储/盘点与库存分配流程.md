# 盘点与库存分配流程

> 代码依据：`InventoryCheckServiceImpl`、`InventoryAssignServiceImpl`、`OtherInboundServiceImpl`、`OtherOutboundServiceImpl`。

## 一、盘点单（InventoryCheck）

状态机：1 新建 → 2 待审核 → 3 已审核。盘点类型：1 盘盈 / 2 盘亏。

### 1. 新增/编辑
- 按 仓库+盘点类型 建单，明细行：SKU、货权层级、盘点数量（>0）；
- 仅新建状态可编辑。

### 2. 提交（submit）
- 状态 新建→待审核；
- **盘亏单提交即占用库存**（业务类型 盘点出库锁定 INVENTORY_CHECK_OUTBOUND_BOOKING，-500）：防止审核期间库存被其它业务动用；盘盈单不占用。

### 3. 审核（audit）
- 仅待审核可审核，否则报"盘点单不是待审核状态"；
- **通过** → 已审核，并立即执行库存操作：
  - 盘盈：盘点入库（INVENTORY_CHECK_INBOUND，+2），明细数量>0 的行入库；
  - 盘亏：盘点出库（INVENTORY_CHECK_OUTBOUND，-2），走 **锁定出库**（核销提交时的占用）；明细为空报"盘点单【x】明细为空"；
  - 其它类型报"盘点类型错误"；
- **拒绝** → 回新建；盘亏单同时 **释放占用**（盘点出库释放，+500）。

### 4. 删除
- 按状态边界删除（已执行库存操作的不可删）。

## 二、其他入库/其他出库（OtherInbound / OtherOutbound）

手工单据，状态机：1 新建 → 2 待审核 → 3 已审核。

**共同边界（新增/编辑）**：
- 明细行：SKU 非空、货权层级非空、数量>0；
- 同一单内 "SKU+货权归属" 必须唯一，否则报"要唯一，请检查明细行"；
- 仅新建状态可编辑。

**其他入库**：审核通过 → 其他入库（+100）直接入库（入库不校验负库存，是允许负库存的入口之一）。

**其他出库**：
- 提交 → 待审核，同时 **占用库存**（其他出库锁定，-400）；
- 审核通过 → 其他出库（-100）走锁定出库；
- 审核拒绝 → 回新建并 **释放占用**（其他出库释放，+400）。

## 三、库存分配（InventoryAssign）

同仓库内不同货权层级之间转移可用库存（详见 [[库存]] 第六节）：
- 手工分配：来源层可用不足即拒绝；
- 自动调平任务：按仓库消化负库存层级（全额或按比例摊分）。

## 四、边界汇总

- 盘亏与其它出库类单据遵循"提交占用、审核通过核销出库、审核拒绝释放"的三段式；
- 盘盈与其它入库审核通过才落库存；
- 所有单据状态机单向推进，审核拒绝只能回新建（不能直接作废已审核单）；
- 明细必须带货权层级，且同单内层级+SKU 唯一。
