# 发货与出库流程

## 流程主线

```text
物流计划批次(已审核)
  → 调拨单(待推单 0)
  → 生成发货单 + 自动审核（"调拨计划推单自动审核"）→ 待发货 2
  → 发货(shipping，始发仓出库) → 已发货 3
  → 推送第三方仓 / 生成收货单 / 在途退运
```

## 物流计划批次（LogisticsPlanBach）

- 状态（`LogisticsPlanBachStatusEnum`）：草稿 → 待审核 → 已审核 → 执行中 → 已完成 / 已关闭；`CANCEL` 为兼容旧代码，语义同已关闭。
- 明细状态（`LogisticsPlanBachItemStatusEnum`）：未推送 → 已推送 → 执行中 → 已发货 → 已关闭。
- 入口：导入（引用 FBA 货件数据 / 导入非 FBA 批次数据）、手动编辑；提交（commit）、审核（audit，通过后生成调拨单）、关闭（close，仅草稿）、补推（supplementaryPush，仅已审核/执行中）。
- 随发货单状态联动：`updateStatusByShipment`；调拨被删除时明细回退未推送（`onAllocateDelete`）。

## 调拨单（Allocate）

- 状态（`AllocateStatusEnum`）：0 待推单 → 1 已推单；`-1` 为弃用值（历史命名"待审核"）。
- 生成：`createAllocateByLogisticPlan`（物流计划批次审核通过时按批次+仓库维度生成）。
- 生成发货单：`generate`/`batchGenerate`，仅"待推单"可生成；生成后发货单置为待审核并**自动审核**进入待发货，调拨置为已推单。
- 反审核（converseAudit）可将调拨从已推单退回待推单。
- 校验：始发/目的仓 SKU 维护完整性；批量生成使用 `ALLOCATE_LOCK_KEY` 分布式锁。

## 发货单（Shipment）

- 状态（`ShipmentStatusEnum`）：0 草稿 / 1 待审核 / 2 待发货 / 3 已发货（4 完成已注释弃用）。
- 推送状态（`ShipPushStatusEnum`）：0 未推送 / 1 推送成功 / 2 推送失败 / 3 无需推送；入库推送（ReceiptOrderStatusEnum：未推送/推送成功/推送失败/无需推送）。
- 操作：
  - 发货 `shipping`：校验待发货状态与装箱信息，始发仓出库（SHIPMENT_OUTBOUND），置已发货。
  - 推送第三方仓 `pushToThirdWh` / 批量推送：仅待发货且未推送/推送失败。
  - 手动标发 `batchSend`；截单 `cancel`。
  - 生成收货单 `generateReceiptV2` / 平台仓自动 `autoGeneratePlatReceipt`。
  - 在途退运 `createReturnOnroad`（见 [[退货与退运流程]]）。

## 平台货件（PlatformPlan，FBA）

- 状态（`PlatformPlanStatusEnum`）：0 待提交 → 1 入库计划创建中 → 2 待确认打包 → 4 待确认放置地 → 6 待确认运输方式 → 8 待审核 → 9 待预报 → 10 已预报；-1 取消。
- 与亚马逊 SP-API 交互：创建/回调（fbaCallback）、确认打包（confirmPack）、确认放置（confirmPlacement）、确认运输（confirmTransport）、审核、预报（finish）。

## 其他出库（OtherOutbound）

状态 新建 1 → 待审核 2 → 已审核 3；审核后生效。出库类型包括调拨出库（-3）、销售出库（-4）、其他出库（-100）、盘点出库（-2）等。

## 废弃提示

对照 [[前端WMS废弃接口清单]]：

- 发货单 submit/audit/delete/batchSubmit/batchAudit/batchDelete/batchDownloadCheck/downloadError 前端已无入口（D 类），当前生产由"调拨推单自动审核"进入待发货，不要按 草稿→提交→审核 的旧链路理解。
- 调拨 submit/audit/export（D 类）与 cancel（A 类）已废弃；创建发货单走"生成发货单"而非提交/审核。
- 采购交期发货计划（DeliveryPlan）的 edit/submit/logicConfirm/purchaseConfirm/delete 已废弃（A/B 类），前端仅列表/详情/导出在用。
- 物流计划批次 remove/bachRemove/importFbaLogisticsPlanByPlatform 已废弃（A/B 类）。
