# 收货与入库流程

> 代码依据：`ReceiptNewServiceImpl`、`ReceiptItemServiceImpl`、`InboundServiceImpl`、`AbstractInboundServiceImpl` 及各入库实现、`job/AutoGenerateReceiptJobHandler`。

## 一、收货单来源

收货单（ReceiptNew，单号前缀 SH）由 **调拨发货单** 汇总生成：
1. **手工生成**：界面选中多张发货单 → `preSummaryReceipt` 预览（按物流计划批次+目的仓等分组）→ `generateReceiptFromPreView`：
   - 按 SKU+MSKU+目的仓SKU+货权+排柜计划号+服务商入库单号+订单号 汇总发货明细为收货明细（数量=各发货单之和，并携带已退运数量）；
   - 收货单 `orderStatus`：发货单未推送/推送失败 → 99（未推送）；推送成功/无需推送 → 0；
   - 回写各发货单的收货单号；发货单的箱子挂到收货单并编收货箱号；
2. **自动生成**：`autoGeneratePlatReceiptJob` → `shipmentService.autoGeneratePlatReceipt()`（平台仓类发货单自动生成收货单）；
3. 一张收货单对应一个物流计划批次与一个目的仓，可覆盖多张发货单。

## 二、收货单状态（ReceiptNewStatusEnum）

0 未收货 → 5 部分收货 → 10 已收货。

## 三、签收方式

### 1. 手动签收（receive）
- 加收货单锁 `RECEIPT_LOCK_KEY+id`（等待 0.5s/持有 180s），占用报"该收货单正在操作中"；
- 按 三方SKU+服务商入库单号 汇总签收参数，分摊到收货明细（`allocateReceiveQuantityBySku`）；
- 构建入库信息（`receiveAndBuildInboundInfo`）：按发货单+入库单号聚合；
- 逐发货单执行 **调拨入库**（业务类型 SHIPMENT_INBOUND，入库仓=目的仓，源单号=收货单号）；
- 签收数量回写发货单明细（已收货数量，按 SKU+货权匹配；无法定位时按收货单关联发货单顺序分摊）；
- 状态重算：已收+已退运+已取消 ≥ 应收 → 已收货；已收>0 → 部分收货。

### 2. 整单签收（receiveAll / receive(idSet)）
- 批量用 MultiLock；每单：应收=发货数-已退运-已取消，全部置为已收，走同样的入库+回写流程，状态直接置已收货。

### 3. 第三方仓自动回传（createInboundJob/queryInboundJob）
- `createInbound`：把待推送的收货单推送三方仓创建入库单（回写服务商入库单号）；
- `queryInbound`：轮询三方仓入库结果，`afterQueryInbound` 按三方仓实收数据回写签收并入库；
- 收货单按第三方 SKU 签收（`receiveByThirdSku`）：以三方仓实收 SKU/数量为准。

### 4. Wayfair CG 自动收货
- `wayfairAutoReceiveJob` 等：按 Wayfair 交易文件自动生成收货/账单数据。

## 四、结束到货（finishReceive）

处理"剩余数量不再收货"的场景（仅未收货/部分收货可操作）：
1. 明细取消数 = 发货数 - 已收 - 已退运 - 已取消（无待取消数量则拒绝）；
2. 取消数量回写发货单明细；
3. 更新箱子/箱明细取消数量与箱状态（箱内全取消=已取消，部分=部分取消）；
4. 按发货单生成 **结束到货出库单**（业务类型 FINISH_ARRIVAL_OUTBOUND，-9），扣减目的仓对应 **在途库存**；
5. 收货单置已收货。

## 五、入库通用流程（AbstractInboundServiceImpl.addInbound）

1. 校验业务类型/仓库/编码/明细（明细行需含货权层级）；
2. 生成入库单；
3. 批次处理（新建或核销在途）；
4. 总账+私有账加库存、记日志；
5. 扩展回调（如退件入库回写退件单）。

各入库实现（InboundTypeFactory 按 BoundTypeEnum 路由）：
- 采购入库（PMS 到货触发）；
- 调拨入库（收货签收触发，核销批次在途）；
- 退货入库（退件单质检后，良品入指定货权层级）；
- 完工入库（PMS 质检完工）；
- 盘点入库、其他入库、采购调整入库、在途退运入库。

## 六、边界汇总

- 签收数量不能超过剩余应收（分摊逻辑保证）；已退运/已取消数量在计算可收量时扣除；
- 同一收货单并发签收被收货单锁阻塞；
- 入库必须带货权层级，否则报"库存层级为空"；
- 调拨入库会核销目的仓批次在途，未出库过的批次无法核销；
- 结束到货只在未收货/部分收货状态可用，且必须存在待取消数量；
- 三方仓入库单未推送成功（收货单 orderStatus=99）时不走三方仓同步，仅本地签收。
