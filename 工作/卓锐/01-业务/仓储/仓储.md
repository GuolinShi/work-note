# 仓储（WMS）

仓储由 `xzy-wms` 服务承担：头程物流计划、调拨计划、调拨发货单、收货签收、入库出库、库存账（总账/私有账/批次/锁定/在途）、盘点、库存分配、退件与在途退运、第三方仓（海外仓）对接、亚马逊 FBA 货件、Wayfair CG 库存。

> 本文档 2026-09-04 基于 `xzy-erp-public/xzy-wms` 源码重新梳理，替代旧版。

## 核心对象

| 对象 | 模型 | 职责 |
| --- | --- | --- |
| 交货计划 | DeliveryPlan / DeliveryPlanItem | 采购侧交货计划（草稿→采购确认→物控确认→已确认），物流批次从这里"下达"数量 |
| 物流计划批次 | LogisticsPlanBach / Item | 头程物流计划（草稿→待审核→已审核→执行中→已完成/关闭/作废），审核后生成调拨计划 |
| 调拨计划 | Allocate / AllocateItem | 状态：0 待推单 / -1 已推单（审核中）/ 1 已推单（审核通过）；可生成多张调拨发货单 |
| 调拨发货单 | Shipment / ShipmentItem | 头程发货主单：草稿→待审核→待发货→已发货（待收货）；出库+推送三方仓的载体 |
| 收货单 | ReceiptNew / ReceiptItem | 按物流批次把多张发货单汇总成一张收货单（SH 单号）；未收货/部分收货/已收货 |
| 箱子 | Box / BoxItem | 发货装箱；签收/退运/取消按箱推进；箱状态：未收货/部分收货/已收货/已退运/部分取消/已取消 |
| 入库/出库单 | Inbound / Outbound + Item | 库存增减的单据载体，按业务类型（BoundTypeEnum）区分 |
| 其他入/出库 | OtherInbound / OtherOutbound | 非业务链路的手工出入库（新建→待审核→已审核） |
| 盘点单 | InventoryCheck / Item | 盘盈入库 / 盘亏出库（新建→待审核→已审核） |
| 库存分配 | InventoryAssign / Item | 同仓库不同货权层级之间的可用库存调拨 |
| 库存总账 | Inventory | 仓库+SKU 维度：可用/锁定/采购在途/调拨在途/不良/待上架/样品/二手 |
| 私有库存 | InventoryPrivate | 仓库+SKU+货权层级（privateId）维度，同字段结构 |
| 库存层级 | InventoryLevel / InventoryLevelShop | 货权层级树；店铺扣减优先顺序（店铺→层级列表） |
| 批次 | InventoryBatch / Record / Onroad | 入库批次（部分业务新建批次），出库按 FIFO 扣减；调拨出库产生批次在途 |
| 锁定库存 | InventoryLock | 占用明细（锁定批次 lockBatch），出库/释放时核销 |
| 退件单 | Return / ReturnItem | RMA 同步或手工导入；待提交→待质检→待入库→已完成/已作废 |
| 在途退运 | ReturnOnroad / Item | 已发货单的整箱退运：创建即出库+入库 |
| 平台货件 | PlatformPlan | 亚马逊 FBA 入库计划（SP-API 流转） |
| FBA 绑定 | AmzInboundBind / Item / Box | 平台货件与箱/发货单的绑定关系 |

## 库存操作类型总表（BoundTypeEnum）

规则：入库正数、出库负数；锁定（lock）= 占用可用转锁定；释放（unlock）= 锁定转回可用。

| 类别 | 类型 | 说明 |
| --- | --- | --- |
| 入库 | 1 采购入库 / 2 盘点入库 / 3 调拨入库 / 4 退货入库 / 5 维修入库 / 6 完工入库 / 7 采购调整入库 / 8 在途退运入库 / 100 其他入库 | 各业务入库 |
| 出库 | -1 采退出库 / -2 盘点出库 / -3 调拨出库 / -4 销售出库 / -7 采购调整出库 / -8 在途退运出库 / -9 结束到货 / -100 其他出库 | 各业务出库 |
| 锁定 | -200 订单锁定 / -300 头程发货锁定 / -400 其他出库锁定 / -500 盘点出库锁定 / -700 采购调整锁定 | 占用（可用→锁定） |
| 释放 | 200 订单释放 / 300 头程发货释放 / 400 其他出库释放 / 500 盘点出库释放 / 700 采购调整释放 | 释放（锁定→可用） |
| 分配 | 1000 库存分配 / 1100 库存自动分配 | 货权层级间调库存 |

## 仓库类型与对接

- 仓库（Warehouse）：`integrated` 表示是否对接（一体化）；`whType` 区分自有仓/第三方仓；`whAccount` 为三方仓账号。
- 第三方仓对接：递四方（fpx）、易仓（eccang）、领星（lingxing）等，经 openapi 服务（`RemoteOpenapiWhService`）推送出库单/入库单、查询状态、取消。
- 平台仓：亚马逊 FBA（SP-API）、Wayfair CG。
- 字典 `wms_not_push_warehouse` 配置"不推送"的仓库（收货单/发货单按此决定推送状态）。

## 流程总览

```text
采购侧：交货计划(采购/物控确认) → 下达数量 → 物流计划批次(审核) → 调拨计划(推单审核) → 调拨发货单
发货侧：发货单提交(钉钉流程) → 审核通过(占用库存) → 发货(始发仓调拨出库+批次在途) → [推送三方仓出库] → 运输
收货侧：发货单生成收货单(按物流批次汇总) → 签收(手动/整单/三方仓同步) → 调拨入库(目的仓) → 回写发货单已收数量
         结束到货：未收数量取消 → 扣目的仓在途库存
退货侧：RMA/手工 → 退件单 → 提交 → 质检 → 入库(良品入货权层级)；在途退运：已发货单整箱退运，创建即出+入
库存：占用/释放/锁定出库 三套机制；负库存自动调平任务；每日库存快照
```

## 并发控制

- 库存可用量锁：按仓库 `INVENTORY_AVAILABLE_LOCK_KEY+whId`（占用时 tryLock 60s 等待/120s 持有）；
- 单据锁：调拨计划 `ALLOCATE_LOCK_KEY`、发货单 `ALLOCATE_SHIPMENT_LOCK_KEY`、物流批次 `LOGISTICS_PLAN_LOCK_KEY`、收货单 `RECEIPT_LOCK_KEY`（MultiLock 支持批量）、退件 `RETURN_LOCK_KEY`；
- 任务锁：各 XxlJob 有全局锁防止重入。
