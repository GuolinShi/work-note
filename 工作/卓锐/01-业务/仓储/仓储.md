# 仓储（WMS）

仓储由 `xzy-wms` 服务承担，负责收货、签收、入库、库存管理、调拨、发货、出库、退货、在途退运，以及与第三方仓/平台仓的对接。

## 核心对象

| 对象     | 表/模型                                            | 职责                               |
| ------ | ----------------------------------------------- | -------------------------------- |
| 收货单    | ReceiptNew / ReceiptItem                        | 以发货单（或平台仓货件）为来源，按入库单号汇总签收        |
| 发货单    | Shipment / ShipmentItem                         | 头程发货主单，由调拨单生成，发货后进入收货链路          |
| 调拨单    | Allocate / AllocateItem                         | 计划调拨，由物流计划批次生成，可生成发货单            |
| 入库/出库  | Inbound / Outbound、OtherInbound / OtherOutbound | 库存增减的实际载体，按业务类型（BoundTypeEnum）区分 |
| 库存总表   | Inventory                                       | 仓库+SKU 维度的汇总库存                   |
| 私有库存   | InventoryPrivate                                | 仓库+SKU+货权层级（privateId）维度的库存      |
| 库存层级   | InventoryLevel                                  | 库存结构树，公共层级（parentId=0）不可删除       |
| 物流计划批次 | LogisticsPlanBach / Item                        | FBA/头程物流计划，审核通过后生成调拨单            |
| 平台货件   | PlatformPlan                                    | 亚马逊入仓计划（FBA），走 Amazon SP-API 流转  |
| 退货     | Return                                          | 客户/物流退件，RMA 同步或手动导入              |
| 在途退运   | ReturnOnroad / Item                             | 已发货单的整箱退运，创建即执行                  |
| 箱子     | Box / BoxItem                                   | 发货装箱信息，签收/退运按箱推进                 |
| 批次     | InventoryBatch                                  | 库存批次，出库按 FIFO                    |

## 系统边界

- 上游：PMS 采购/质检/完工（采购入库 V2 会创建 WMS 入库）；SRM 事件；OpenAPI 多平台数据；亚马逊 SP-API。
- 下游：第三方仓（递四方 fpx、易仓 eccang、领星 lingxing）、平台仓（wayfair、亚马逊 FBA）、库存同步（lingxing/eccang/yqn）。
- WMS 不直接写 PMS/FMS 数据表；跨模块通过内部接口（xzy-wms-api / xzy-pms-api）协作。

## 流程总览

```text
采购到货侧：发货单(已发货) → 收货单 → 签收(手动/整单/第三方自动) → 入库 → 库存
发货侧：物流计划批次 → 调拨单 → 发货单(自动审核) → 发货/出库 → 推送第三方仓 → 收货
FBA 侧：物流计划批次 → 平台货件(Amazon SP-API) → 预报 → 收货
退货侧：RMA/手动 → 退货单 → 质检 → 入库预报/入库
退运侧：已发货单 → 在途退运单(整箱) → 出库+入库一次完成
```

## 废弃代码提示

仓储模块存在较多"有方法但无有效 UI 入口"或"前端无引用"的接口，读取代码时请先对照 [[前端WMS废弃接口清单]]，跳过其中的接口，不要将其当作真实业务流程依据。典型注意点：

- 发货单的提交/审核/删除/批量操作（submit/audit/delete/batch\*）在前端已无入口；实际由"调拨推单自动审核"进入待发货。
- 调拨单的提交/审核/导出已废弃。
- 采购交期发货计划（DeliveryPlan）的编辑/提交/确认已废弃，前端仅保留列表/详情/导出。
- 物流计划批次的删除/批量删除/按平台导入已废弃。
