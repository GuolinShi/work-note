# 对接领星-调拨单与FBA发货单同步-待确认问题清单

> 关联方案：[[对接领星-调拨单与FBA发货单同步-技术实现方案]]
> 说明：以下问题按 **A=PRD缺漏/歧义、B=领星接口与数据口径、C=技术方案决策、D=前置条件** 分组。每题附【建议方案】，如无意见可直接按建议执行。

## A. PRD 缺漏与歧义（需产品确认）

### A-1 备货单场景本期如何处理？★
PRD 调拨计划分类中提到"移库调拨：自营仓/供应商仓 → 非FBA平台仓/第三方仓 —— 备货单"，但 PRD 正文与同步范围表只覆盖调拨单和 FBA 发货单，未给出备货单的接口与流程（备货单疑似不在本次提供的 API 文档范围内）。
**建议**：本期该场景不同步领星（仅在中台打标 `lx_doc_type=STOCKUP`），业务暂按人工在领星建备货单；备货单同步另立需求。请确认。

### A-2 平台仓（非FBA）在中台的仓库类型口径？★
分类规则依赖仓库类型判断，中台 `wh_type` 仅有：1自营、2第三方、3供应商、4FBA。"平台仓（非FBA）"（如 Wayfair/Lazada 平台仓）在中台归为哪类？
**建议**：按现有数据，非FBA平台仓归入"第三方仓(2)"处理，即与第三方仓走同一分支。请确认或给出区分方式。

### A-3 PRD"数据同步策略"中【同步内容】【同步时机】两项为空白
**建议**：按方案文档第 0 节口径执行（内容=调拨单/发货单创建、收货、结束到货、退运撤销、费用；时机=发货点击时及后续操作触发，最晚时机同步）。

### A-4 "同步范围"表格第 2、3 行为空
**建议**：本期同步范围即表格第 1 行所述（调拨发货单→领星调拨单/发货单），无其他模块。请确认。

### A-5 费用弹框【确定】的保存范围？
弹框下方展示物流计划下所有发货单及分摊预览。点击【确定】时：仅保存当前这张发货单的分摊费用，还是批量保存该物流计划下所有发货单的费用？
**建议**：批量保存全部（业务一次录入 SO 总费用，批量落库效率更高；已发货的 FBA 单逐单触发领星费用同步）。请确认。

### A-6 结束到货后发货单的回写口径？
PRD："结束到货的数量回写到发货单"。发货单明细上"取消数"是否需要落库展示（目前 `t_wms_shipment_item` 无取消数字段）？发货单最终是否要流转到某个终态（当前状态机 已发货 后无"完成"态）？
**建议**：发货单明细增加 `cancel_qty`；发货单状态维持现状（不新增完成态），收货单全部收货/结束到货即代表链路完结。请确认。

### A-7 领星单据悬浮弹框的展示字段
PRD 截图无法查看具体内容。
**建议**：悬浮弹框展示：领星单据类型、领星单号、同步状态、预估物流费、实际物流费、同步/作废时间、失败原因（如有）。请确认。

### A-8 调拨单类的费用=0 二次确认提示文案与交互
PRD 已给文案。确认交互为：模态框【正确并发货】/【取消】，点【正确并发货】继续发货流程。

## B. 领星接口与数据口径

### B-1 接口签名算法文档缺失 ★
本地爬虫文档缺少 Guidance/TestSign 章节（签名生成规则、全局错误码、限流细节）。
**建议**：由对接人提供领星官方签名说明或测试代码（知识库第4项"接口测试代码"）；联调阶段第一个任务即校准签名。

### B-2 领星库存不足导致建单失败的处理？
CreateSendedOrder 会直接**扣减**领星发货仓库存；若领星侧可用库存不足（如被其他单据占用）会失败。
**建议**：发货阻断并提示"领星库存不足"，由业务核对领星库存后重试。是否需要发货前预检领星库存（额外接口调用）？默认不预检。

### B-3 调拨单费用分摊参数 fee_part_type 口径？
中台已将费用分摊到发货单粒度（领星单与发货单1:1）。
**建议**：创建调拨单时 `fee_part_type=0`（不分摊），`freight_fee/other_fee` 传该发货单的实际费用合计。请确认。

### B-4 次品调拨是否支持？
领星 AddAllocationOrder 支持 good_num/bad_num；中台发货单明细目前只有 shipmentQty。
**建议**：本期全部按可用量 good_num 传递，不支持次品（与中台现状一致）。请确认。

### B-5 "单品包装重量"取净重还是毛重？
计费重=MAX(单品包装重量,体积重)。`t_pms_product_spec` 同时有 netWeight（净重）/grossWeight（毛重）。
**建议**：取毛重（grossWeight），与领星字段 cg_product_gross_weight 的语义（领星文档该字段注释为"单品净重"但命名毛重，实际以领星商品管理"单品毛重"为准）对齐。请确认。

### B-6 无箱规/无包装尺寸的产品如何处理？
体积重计算依赖包装尺寸与单箱数量，部分 SKU 可能缺失。
**建议**：缺失时该 SKU 体积重/计费重按 0 计，弹框给出黄色提示（不阻断）；调拨单类发货不阻断。请确认。

### B-7 调拨单退运反向调拨的数量口径？★
反向 type=1 调拨单的数量：按原调拨单全部数量，还是按本次退运数量？（中台退运支持部分退运、且仅整箱）
**建议**：按原调拨单全部数量反向归还（领星侧原单已全额收货，必须全额反向才能账实平衡）；中台的部分退运差异由中台库存账承担。请确认——这是退运方案的关键口径。

### B-8 "默认物流商"下有多个渠道时取哪个？
按计费重分摊时必传 logistics_channel_id。ChannelList 中 provider=默认物流商 的渠道可能有多个。
**建议**：配置项指定一个默认渠道ID（`t_lx_channel` 加"默认"标记），由业务维护。请确认。

### B-9 调拨单明细 seller_id 是否传递？
AddAllocationOrder 的 product_list>>seller_id 可不传（默认0）。
**建议**：不传（默认0），仅 FBA 发货单需要店铺维度。请确认。

### B-10 领星发货单状态回查
悬浮弹框/对账是否需要展示领星侧实时单据状态？可用 `FBA/GetInboundShipmentList` 查询。
**建议**：本期不做实时回查，仅展示中台记录的同步状态；对账 job 按需抽查。请确认。

## C. 技术方案决策（需技术负责人确认）

### C-1 领星客户端落位：xzy-wms 服务内 ★
**建议**：领星 OpenAPI client 直接建在 xzy-wms（理由见方案 2.1：发货需同步拿结果决定事务、避免跨仓库改动）。若要求统一收口 xzy-openapi 服务，则需跨仓库排期。

### C-2 发货一致性策略：领星失败即阻断发货 ★
**建议**：发货时先调领星，领星失败则发货整体失败（中台不出库、不转状态），业务整改后重新点发货。理由：领星单据创建即锁/扣领星库存，先中台后领星会产生"中台已出库、领星无单"的悬挂态且调拨单无法撤销。请确认。

### C-3 领星收货失败不回滚中台收货
**建议**：中台收货事务为主，领星调用失败走重试队列补偿（领星侧晚收货不影响中台账）。请确认。

### C-4 作废发货单参数
**建议**：`isReturnStock=1`（恢复产品库存）、`isReturnStockAux=0`（辅料不恢复）、cancelReason=中台退运单号。请确认。

### C-5 收货单文案与多选筛选实现方式
【未收货】→【待收货】仅文案调整（枚举值不变）；状态筛选改多选（后端查询条件改 in）。无争议项，仅告知。

### C-6 FBA发货单创建时 head_fee_type 的默认值 ★
头程费分配方式只能在创建时设定（updateListLogistics 无此参数），但费用弹框允许发货后再选分摊方式——两者存在时序矛盾。
**建议**：发货时若已录费用且选"计费重"→传 0+logistics_channel_id；其余情况（含未录费用）默认传 2（按体积重）。发货后费用弹框的"分摊方式"仅用于中台费用分摊计算与领星费用覆盖更新，不再改领星分摊方式。请确认该口径（或要求发货前强制选择分摊方式）。

### C-7 费用币种与单价口径
领星费用字段必传币种与单价（price）。
**建议**：币种固定 CNY；单价=物流费/总计费重（无计费重时传 0）。请确认。

### C-8 SO/物流单号是否同步到领星跟踪信息？
updateListLogistics 的 tracking_list 可传跟踪号。
**建议**：本期不同步（PRD 未要求），仅写入领星单据备注（创建时已含）。请确认。

### C-9 截单回退待推单功能是否已满足需求？
代码已存在 `resetAllocateToWaitPush`（截单后调拨计划自动回待推单，2026-07 修改）。
**建议**：视为已实现，本期仅回归测试。请产品确认。

### C-10 告警渠道
**建议**：复用现有工作台异常消息（ErrorMsgTypeEnums）+ 服务端日志；是否额外接钉钉机器人？

### C-11 领星"锁库存"语义差异提示
PRD 称"领星创建执行单据时锁库存"，实际 CreateSendedOrder 是**直接扣减**发货仓库存、AddAllocationOrder 创建即扣减始发仓库存（调拨在途）。方案按此语义设计，无需动作，仅提示知悉。
